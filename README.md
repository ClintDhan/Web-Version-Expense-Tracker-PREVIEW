## Key Features

Dashboard Overview – View financial summaries, including total income, expenses, and available balance.

Transaction Management – Add, view, and delete financial transactions.

Income and Expense Tracking – Categorize transactions to distinguish between money received and money spent.

Data Visualization – Visualize financial activity through interactive charts using Chart.js.

Transaction History – Review previously recorded transactions.

Persistent Data – Store transaction records using the browser's Local Storage API.

Responsive Design – Access the application across different screen sizes and devices.

## Technologies Used

HTML5

CSS3

JavaScript

Chart.js

Bootstrap Icons

Local Storage API

## How It Works

Add a transaction by providing its details and amount.

Specify whether the transaction represents income or an expense.

The application updates the financial summaries based on recorded transactions.

View transaction history to monitor financial activity.

Analyze spending patterns through interactive charts.

Transaction records remain available through browser local storage.
